# Elastic Stack (ELK Stack) (elk-stack)
The Elastic Stack (formerly known as ELK Stack) is a collection of open-source  products - Elasticsearch, Logstash, and Kibana - designed for taking data from  any source, in any format, and searching, analyzing, and visualizing it in real time.


**URL:** [Visit APIs.json URL](https://www.elastic.co/apis.json)

## Tags:

## APIs

### Elasticsearch API
Distributed, RESTful search and analytics engine capable of addressing a  growing number of use cases. Serves as the heart of the Elastic Stack for  centralized storage and search.


**Human URL:** [https://www.elastic.co/elasticsearch/](https://www.elastic.co/elasticsearch/)

### Kibana API
Data visualization and exploration tool for reviewing logs and events.  Provides real-time histograms, line graphs, pie charts, and maps for  Elasticsearch data.


**Human URL:** [https://www.elastic.co/kibana/](https://www.elastic.co/kibana/)


#### Tags:

#### Properties

### Logstash
Server-side data processing pipeline that ingests data from multiple sources,  transforms it, and sends it to a "stash" like Elasticsearch. Supports various  input, filter, and output plugins.


**Human URL:** [https://www.elastic.co/logstash/](https://www.elastic.co/logstash/)


#### Tags:

 - Data Pipeline, ETL, Data Processing, Log Collection

#### Properties

- [Configuration](https://www.elastic.co/guide/en/logstash/current/configuration.html)
